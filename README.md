# Final Project - BNI University 2026 | Data Engineer

Repositori ini adalah bagian dari submission final project training Data Engineer di BNI University

Struktur repo:

airflow/ -> direktori ini berisi DAG dalam python yang dapat dieksekusi oleh Apache Airflow
scripts/sql -> direktori ini berisi SQL scripts (DDL dan definisi fungsi lain)

SQL scripts dibagi lagi menurut layer-nya, terdapat layer bronze dan silver.
